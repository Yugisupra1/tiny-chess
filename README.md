A 4 KB Python chess engine: 0x88 negamax with alpha-beta, iterative deepening on a fixed 60,000-node budget, transposition table, quiescence and anti-repetition. Practice Elo ~1,545 against the house gauntlet.

## Run it

```sh
python3 -P -s main.py
```
